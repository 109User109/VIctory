# Bitácora de pruebas locales

Este fork registra la preparación y las pruebas para intentar reproducir el
video de arranque y navegar los menús de GTA VI en Windows con gráficos
integrados. Llegar a la primera escena 3D es un objetivo distinto.

- [2026-11-25: preparación inicial en Ryzen 5 7530U](2026-11-25-windows-menu.md)
- [2026-11-25: presentación del fork en español](2026-11-25-readme-es.md)
- [2026-11-25: hashes y primeras pruebas de arranque](2026-11-25-first-boot.md)
- [2026-11-25: análisis comparado de la pantalla negra](2026-11-25-log-analysis.md)
- [2026-11-25 · Prueba 01, intro y entrada a Vice City](2026-11-25-prueba-01.md)
- [Scripts de compilación e inicio](../../scripts/windows/README.md)

Para cada sesión nueva, agregar una entrada con fecha, revisión de código,
hardware y controlador, comando, resultado observado y limitaciones. Distinguir
siempre las pruebas de la herramienta de la ejecución real del juego. Registrar
los cambios en un commit y agregar aquí el enlace a la entrada.

Los resúmenes revisados se versionan. Los registros crudos, las rutas personales,
los guardados, las cachés y los archivos del juego permanecen fuera del repositorio,
conforme a la [política de archivos](../asset-policy.md).

El trabajo asistido por Codex se atribuye con el trailer de commit
`Assisted-by: OpenAI Codex`. Esta atribución no representa una cuenta de GitHub
ni concede permisos de acceso al repositorio.
